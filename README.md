# 🧪 SPECIAL REAGENT MAKER

> **A Dynamic Web Utility for Laboratory Reagent Preparation & Recipe Scaling**

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](CONTRIBUTING.md)
[![PWA Ready](https://img.shields.io/badge/PWA-Ready-0f172a.svg)](#-progressive-web-app-pwa)

**SPECIAL REAGENT MAKER** is a progressive web application designed for analytical chemists, pharmacognosists, researchers, and students. It eliminates manual calculations and chemical waste by automatically scaling stoichiometric reagent preparation protocols to any target batch volume or custom concentration.

---

## ✨ Features

- **⚡ Dynamic Batch Scaling:** Automatically calculates required chemical masses and solvent volumes in real-time based on your target volume ($mL$) or concentration ($\% w/v$).
- **📚 Integrated Qualitative Reagent Library:** Includes pre-configured preparation protocols for 14 essential laboratory reagents:
  - **Carbohydrate Tests:** Seliwanoff's, Molisch's, Barfoed's, Benedict's, Tollens'
  - **Alkaloid Tests:** Mayer's, Dragendorff's, Wagner's, Hager's
  - **Protein & Amino Acid Tests:** Millon's, Esbach's, Ninhydrin
  - **Bilirubin & Aldehyde Tests:** Fouchet's, Fehling's (A & B)
- **🧰 Built-In Lab Bench Tools:**
  - **Basic Calculator:** For rapid benchtop calculations directly within the interface.
  - **Unit Converter:** Seamless mass ($g, mg, kg, oz$) and volume ($mL, L, \mu L, fl oz$) conversions.
- **🛡️ Safety & Storage Directives:** Displays handling notes, storage conditions, fume hood warnings, and stability alerts for each reagent.
- **📱 Offline PWA Support:** Installable as a progressive web app for instant, offline desktop and mobile access without relying on lab network connectivity.
- **🌙 Dark / Light UI:** Ergonomic dark and light themes optimized for visibility across different laboratory environments.

## 📥 Installation & Local Setup

Since this project relies on pure standard web technologies, no complex node installation or build pipeline is required.

1. **Clone the Repository:**
   ```bash
   git clone [https://github.com/your-username/special-reagent-maker.git](https://github.com/your-username/special-reagent-maker.git)

```

2. **Navigate to Project Directory:**
```bash
cd special-reagent-maker

```


3. **Run Locally:**
Simply open `index.html` (or `SPECIAL REAGENT MAKER_6.html`) directly in any web browser, or serve it using standard static servers like VS Code's **Live Server**.

## 📱 Progressive Web App (PWA)

To install this utility as a native desktop or mobile app:

1. Open the website in Chrome, Edge, or Safari.
2. Click the **"📲 Install App"** button in the top navigation header (or use the browser's install prompt).
3. Access the app offline anytime from your device's home screen or application launcher.
